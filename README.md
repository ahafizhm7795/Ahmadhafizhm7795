# Big Data Technology Project

## Deskripsi

Project ini merupakan implementasi dasar Big Data menggunakan:

* Python
* Apache Spark
* MongoDB Atlas

## Fitur

* Koneksi ke MongoDB Atlas
* Pengolahan data menggunakan PySpark
* Agregasi data (group by & sum)

## Struktur Project

* `scripts/test_mongo.py` → koneksi database
* `scripts/simple_job.py` → Spark job

## Hasil

* Berhasil koneksi ke MongoDB Atlas
* Berhasil menampilkan tabel agregasi
